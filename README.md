## What is Data Structure?
A **data structure** is a way to **organize and store** data in a computer so that it
can be used efficiently.

## Why Study Data Structures?
- Easier for the implementation of some operations.
- Dramatically increase the speed of the programs.
- Decrease the memory usage.
- Easier for debugging programs. 

## What is Algorithm?
An **algorithm** is a step-by-step **set of instructions** to solve a problem or
perform a task.

## Asymptotic Analysis
Asymptotic analysis is a method of describing the **performance** or **complexity** of an algorithm in terms of time and space as the input size grows. It provides a high-level understanding of how an algorithm behaves with large inputs.

1. **Time Complexity:** A way to represent **the amount of time required by the program to run till its
   completion.**
2. **Space Complexity:** Space Complexity means **the amount of memory space required by the algorithm during its
   execution.**
